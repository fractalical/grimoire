# Гримуар французского

Локальная браузерная игра на React и Vite. Готовый словарь и изображения уже
находятся в `public/`; отдельный сервер и пересборка словаря для запуска не нужны.

## Запуск

Нужен Node.js 22.12+ (рекомендуется Node.js 22, указан в `.nvmrc`). Если установлен nvm:

```bash
git clone https://github.com/fractalical/grimoire.git
cd grimoire
nvm install
nvm use
npm ci
npm run dev
```

Открой **http://127.0.0.1:5173/** в браузере. Терминал с Vite должен оставаться
открытым; остановка — `Ctrl+C`. При следующих запусках достаточно `nvm use`
и `npm run dev`. Если порт занят, останови предыдущий экземпляр Vite.

Без nvm установи совместимую версию Node.js и выполни `npm ci`, затем `npm run dev`
из этой папки. Проверить версию можно командой `node --version`.

Если проект уже скачан, выполняй команды начиная с `nvm install` в папке
с `package.json` (в исходном рабочем каталоге это `French/app`).

Для доступа через туннель скопируй `.env.example` в `.env.local` и укажи его
домен в `GRIMOIRE_ALLOWED_HOSTS`; несколько доменов разделяются запятыми.
Перезапусти Vite после изменения настроек. `.env.local` исключён из Git.

## Сборка

```bash
npm run build
npm run preview
```

Сборка создаётся в `dist/`. Preview обычно доступен на http://127.0.0.1:4173/;
точный адрес указан в терминале. Не открывай `index.html` напрямую через `file://`.

Для раздачи готовой сборки на `0.0.0.0:3000`:

```bash
npm run build
npm start
```

Прогресс сохраняется в браузере после каждого ответа. Используй один и тот же
адрес: `localhost`, `127.0.0.1` и разные порты имеют отдельные хранилища.
В настройках можно скачать и загрузить JSON-копию прогресса.
Прогресс хранится в IndexedDB браузера и не входит в репозиторий.
Скачанные копии `grimoire-*.json` также исключены из Git.

Опубликованы словари уроков 1–20; уроки 21–34 пока готовятся.
В игре 2 296 карточек, включая повторы слов в разных уроках. Это словарная
часть материалов: аудирование и грамматические упражнения PDF не перенесены
как отдельные игровые задания.
Подробности словаря — в [content/README.md](content/README.md).
Команда `npm run content` предназначена для исходного рабочего каталога
`French`: ей нужны соседние `scripts/`, `data/` и `lessons/`, которые не входят
в этот репозиторий. Для запуска, сборки и тестов игры достаточно готового каталога.

## Docker Compose

Из папки приложения:

```bash
docker compose up -d --build
```

Во время сборки образа Vite создаёт готовое приложение в `dist/`.
Контейнер на Node.js 22 выполняет `npm start`: сервер `serve` раздаёт эту папку
на `0.0.0.0:3000`. В итоговом образе находятся сборка и зависимости для её раздачи.
Compose создаёт именованную bridge-сеть `grimoire-network` и подключает к ней
сервис `app`. В конфигурации нет `ports` и `expose`; порты на хост не публикуются.
Для доступа подключи свой reverse proxy к этой сети и направь запросы на
`http://app:3000`. Приложение обслуживается от корня домена.

`GRIMOIRE_ALLOWED_HOSTS` нужен только для локального `npm run dev`.
Готовая сборка работает с доменом, переданным внешним Nginx, без этой переменной.
React и другие зависимости включены в файлы `/assets/`: браузер не запрашивает
`/node_modules/.vite/`, и запуск не зависит от WebSocket Vite.

Локальные `.env`-файлы, сохранения, `node_modules` и исходные материалы уроков
не передаются в контекст сборки. Готовый игровой словарь входит в образ.
Прогресс остаётся в браузере, поэтому отдельный Docker volume для него не нужен.

Просмотр логов и остановка:

```bash
docker compose logs -f app
docker compose down
```

## Прохождение и словари

- Урок разбит на этапы по 10 карточек; последний может быть короче. Например,
  первый урок — 10 этапов по 10 слов. После этапа открывается список пройденных
  слов, можно продолжить или выйти на отдых. Ошибки повторяются внутри этапа.
  Следующий урок и награды открываются после завершения всего урока.
- После верного ответа маг идёт к побеждённому гоблину. Кнопка «Дальше»
  перемещает камеру к следующей встрече. Настройка «Меньше анимации» отключает
  движение, сохраняя новые позиции и прогресс.
- В режиме «Ввод» перевод собирается кнопками из нужных букв и двух лишних.
  Пробелы и знаки препинания подставляются автоматически. Выбранную букву
  можно вернуть в набор, последний выбор — отменить, весь ответ — очистить.
- Направление текстового вопроса выбирается случайно. Оно закреплено за
  встречей и не меняется при переключении формата или перезагрузке.
  Режим картинок доступен для подходящих вопросов с французской подсказкой.
- Полученные книги открываются как словари: том I содержит слова уроков 1–3,
  том II — 4–6 и так далее. Есть перевод, произношение, пример и поиск на обоих
  языках. Повтор урока не стирает уже записанные слова.

Старые сохранения поддерживаются без сброса прогресса; уже полученные книги
тоже становятся словарями. Начатый до обновления урок сохраняет свой набор
слов и получает разбивку на этапы. Расширенный набор урока 6 доступен при новом
прохождении; уже полученный словарь хранит фактически пройденные слова.

## Проверка интерфейса

```bash
npm test
npx playwright install chromium
npm run test:e2e
npm run test:deployment
```

Модульные тесты проверяют наборы букв, стабильность языка, содержимое книг,
границы этапов, повтор ошибок и перенос старых сохранений.
Браузерные тесты открывают отдельные профили и проверяют запуск, ответы,
движение мага, словари, сохранение после перезагрузки, импорт/экспорт и задания.
Мобильная вёрстка проверяется на сенсорных экранах с шириной 320–430 пикселей,
при широкой области просмотра 980 пикселей, смене ориентации и высоты окна.
Отдельная проверка сохраняет компактный вид приложения на компьютере.
Твой прогресс в обычном браузере не меняется.

`test:deployment` проверяет готовую сборку через прокси, который блокирует
скрытые папки и `node_modules`: открытие карты и урока, перезагрузку, загрузку
скриптов, публичный заголовок `Host` и ответы 404 для недоступных файлов.
Для проверки уже запущенного контейнера укажи его HTTP-адрес в
`PLAYWRIGHT_BASE_URL` и запусти `npx playwright test --config playwright.deployment.config.ts`.
