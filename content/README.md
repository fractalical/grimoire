## Проверка ответов

В [editorial.json](editorial.json) перечислены явные `acceptedRu`/`acceptedFr`
для каждой исходной строки уроков 01–05. Во время сборки варианты не угадываются
по разделителям. Полные исходные формы тоже принимаются. Допустимы отдельные
мужские/женские формы и самостоятельные переводы из списка. Проверены общие
дополнения: `житель Венеры`, `продавец рыбы`, `учитель начальной школы` не теряют
последнее слово при разделении. `coucou` допускает ответ `привет` без пояснения.

Для новых строк 06–20 разделитель ` / ` редакционно означает только
самостоятельные варианты ответа. Полная строка также принимается. Например,
`французский / французская` и `студент / студентка` разделяются без потери смысла.
Транскрипция берётся из просмотренной таблицы или ранее проверенной карточки
того же слова и значения. При отсутствии подтверждения поле оставлено пустым.

В игровом экспорте исправлена смешанная строка `neuf / neuve`: это прилагательное
`новый / новая`. Числительное `neuf — девять` уже есть отдельной строкой урока05.
`neuve` не может быть правильным французским ответом на `девять`. Anki не изменён.
Исходный ключ идентичности сохранён в реестре, чтобы эта правка не заменяла ID.

У каждого слова ровно три отвлекающих варианта. Для MVP они выбираются
детерминированно из проверенного пула конкретных слов первого урока: крыша,
карандаш, чай, галстук, жираф, мост, яйцо, суп, солнце, волк, мышь. Проверка
отсекает совпадающие значения, слова и идентичности. Пул сопоставлен со всем
набором переводов: это намеренно простые, разнородные ответы, пригодные для
проверки игрового цикла. Увеличение педагогической сложности и оценка качества
отвлекающих вариантов требуют отдельного пилота. Не используются скрытые
вызовы модели или слова из будущих уроков.

## Изображения

Только **souris, loup, soupe, soleil** имеют режим выбора картинки. Четыре фото
просмотрены визуально; локальный контактный лист `review/image-contact-sheet.jpg`
показывает утверждённый набор. Промежуточные изображения и извлечённые тексты
в `review/` исключены из Git; отчёты проверки сохранены в репозитории.
Каждое изображение служит одним понятием; остальные три —
его отвлекающие варианты. Фотографии содержат мышь, серого волка, миску супа и
солнце в небе. Снимок крыши изнутри и бутербродов с яйцом отклонены как менее
однозначные, жираф не включён из-за отсутствия записи об источнике в реестре.

Файлы локальные, оптимизированные JPEG, до 100 KB каждый, с хешем в имени.
Оригиналы находятся в `anki/media/`. [images.json](images.json) сохраняет
контрольную сумму утверждённых файлов, осмысленные описания, автора и ссылку
Pixabay из существующего `anki/pixabay_attribution.tsv`. Эти сведения также
включены в `imageCredits` публичного каталога. При изменении изображения
требуется повторный визуальный просмотр и обновление контрольной суммы.
Фото — учебные подсказки, пиксельарт игры они не заменяют.

## Сборка и идентичность

Команды ниже выполняются из корня исходного рабочего каталога `French`.
Соседние с `app/` папки `scripts/`, `data/`, `lessons/` и `anki/` не входят
в отдельный репозиторий игры. Готовый `public/content/catalog.json` включён
в репозиторий; для запуска приложения пересобирать его не нужно.

```bash
python3 scripts/build_game_content.py
python3 scripts/build_game_content.py --check
python3 scripts/test_game_content.py
```

Нужны Python 3.10+ и `pdfinfo` из Poppler для проверки страниц. Генератор не
требует pip-пакетов, сети или API-ключа. Pillow использован только при разовой
подготовке уже сохранённых JPEG и контрольного листа, при сборке он не нужен.

В [ids.json](ids.json) закреплены ID словарных единиц и вхождений. Изначально
они получены из SHA-256 пары «французское слово + значение»; вхождение дополнительно
содержит урок. Обычная сборка требует зарегистрированные значения. После проверки
нового материала команда `--register` добавляет только новые ключи. Исправляя
текст существующей записи, редактор переносит её прежний ID на исправленный ключ
в реестре; если значение действительно новое, создаёт новую идентичность.
Удалять старые ключи и регистрировать исправления вслепую нельзя: это разделит
статистику пользователя. Версия каталога зависит от полного содержимого.

Валидатор проверяет манифест из 34 актуальных имён PDF, границы страниц,
принадлежность слов урокам, уникальность ID и вариантов, допустимость ответов,
отсутствие отвлекающих вариантов из будущих уроков, картинки и контрольные суммы.
Тесты отдельно фиксируют повторные слова между уроками, состав PDF06,
составные переводы, `neuf/neuve`, набор фото и детерминированную пересборку.

Уроки 01–05 используют прежний проверенный TSV; повторная постраничная редактура
этих PDF в расширения 06–20 не входила. Уроки 21–34 остаются черновиками.
