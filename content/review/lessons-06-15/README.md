# Проверка словаря PDF06–15

Источник: `lessons/A1 06.pdf` — `lessons/A1 15.pdf`. Просмотрены все 64 страницы
через контактные листы; словарные таблицы и спорные фрагменты увеличены отдельно.
Исходные PDF и Anki не изменялись. Автоматический первый проход в `first-pass/`
сохраняет извлечённый текст и кандидатов, но не используется как готовый словарь:
значительная часть материалов — сканы. PNG страниц и контактные листы сохранены
рядом с этим отчётом для дальнейшей редакторской проверки.

В игру перенесены словарные списки, слова и выражения из диалогов и упражнений,
целевые глаголы из заданий на заполнение пропусков. Формы приводятся к словарной
форме; одинаковые слово и значение внутри урока объединяются. Названия стран
сохранены как тема обучения; имена персонажей и случайные собственные имена
не добавлялись. Числа перенесены из таблиц и видимых заданий, без генерации
всех возможных числовых комбинаций и телефонных номеров.

Всего 1 247 карточек в уроках 06–15. Страница без новых карточек может содержать
аудиозадание без расшифровки, грамматику, повтор уже включённых слов или пустую
таблицу для самостоятельного заполнения. Перенос не означает, что каждое
предложение PDF стало игровой карточкой или что все задания учебника реализованы.

Редакторские решения:

- PDF08, стр. 7: `une saison` — «время года»; ошибочный перевод «месяц» исправлен.
- PDF12, стр. 1: `imaginer` — «воображать / представлять» вместо «изображать».
- PDF11, стр. 2: `neuf / neuve` в контексте `une botte neuve` — «новый / новая»,
  не числительное «девять».
- PDF10, стр. 1: `sixième` — «шестой», несмотря на «седьмом» в переводе примера.
- `secrétariat` из PDF15, стр. 6 сохранено как «секретариат».
- Транскрипции из словарных таблиц записаны в IPA; знак `r` унифицирован как `ʁ`.
  Для остальных слов IPA используется только при наличии прежней проверенной
  карточки с тем же словом и значением. Неподтверждённые поля оставлены пустыми.
- Формы `septante`, `huitante`, `nonante` включены из таблицы PDF14, стр. 4
  вместе с французскими формами десятков; одинаковые переводы не используются
  как отвлекающие варианты друг для друга.

Аудиофайлы, видео, спряжение в пропусках, выбор артиклей, построение отрицаний
и вопросы пока не являются отдельными игровыми упражнениями. Слова из этих
упражнений доступны в режимах перевода и сборки из букв. Новые фотографии не
добавлены; режим картинок использует только прежние четыре проверенные карточки.

Стабильность: прежние 22 ID урока 6 сохранены, уроки 01–05 не пересобирались из
PDF. Начатые прохождения содержат собственный снимок словаря; обновление не
меняет их количество слов. Новый набор открывается при новом прохождении.
